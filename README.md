# 🚗 Insurtech Chain

Веб-приложение для контроля, фиксации и согласования ремонта автомобилей между СТО и страховой компанией.

---

## 📌 Описание проекта

**Insurtech Chain** — это система, обеспечивающая прозрачность процесса ремонта автомобиля.
Она позволяет фиксировать каждый этап работ, подтверждать их фото- и данными, а также согласовывать дополнительные работы между участниками.

Проект направлен на:

* снижение мошенничества
* повышение прозрачности ремонта
* улучшение взаимодействия между СТО и страховыми

---

## 🎯 Цель MVP

Создать работающий веб-интерфейс, который:

* отображает процесс ремонта по этапам
* позволяет фиксировать выполнение работ
* реализует согласование дополнительных работ
* сохраняет все данные в базе

---

## 👥 Роли пользователей

### 🔧 Механик

* просмотр назначенных ремонтов
* выполнение этапов ремонта
* загрузка фотофиксации
* сканирование запчастей
* создание запроса на дополнительные работы

### 🏢 Страховая компания

* просмотр списка ремонтов
* просмотр карточки ремонта
* контроль этапов и фото
* согласование / отклонение допработ

## 🚀 Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/yarikzee/insurtech-chain.git
cd insurtech-chain
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
```

### 3. Активировать окружение

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Настроить переменные окружения

Создай файл `.env` и укажи:

```env
SECRET_KEY=your_secret_key
DATABASE_URL=your_database_url
```

### 6. Применить миграции

```bash
python manage.py migrate
```

### 7. Запустить сервер

```bash
python manage.py runserver
```

После запуска:
👉 http://127.0.0.1:8000/
